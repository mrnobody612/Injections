# Injections

### Process Interaction & Injection Research

This repository contains a collection of examples and research notes related to process interaction, code injection concepts, and runtime behavior in Windows environments.

The examples explore how process-level interactions can affect application execution, system stability, and endpoint security monitoring. Each entry focuses on a specific technique or behavior, its potential impact, and the telemetry that may be generated during execution.

**Security Notice**

Process injection techniques can be abused to conceal malicious activity, interfere with legitimate applications, and evade endpoint security controls. Unauthorized use against systems or processes may result in data exposure, operational disruption, and legal consequences.

All examples should be evaluated exclusively in controlled environments with appropriate authorization. Where applicable, demonstrations are designed to illustrate observable security behaviors without modifying unrelated processes or executing unauthorized code.

The objective is to document relevant behaviors, improve technical understanding, and support the identification of suspicious process activity through defensive monitoring.

*Understand the behavior. Recognize the indicators. Control the risk.*
